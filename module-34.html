34Value

Make value testable, financial, and credible.

Translate operational change into measurable customer value, document assumptions, and build a decision case that survives finance review.

45 min lesson + practiceEvidence-led professional curriculumLevel 4
In this module
  • 1. Define value from the customer side
  • 2. Build a value driver tree
  • 3. Establish a defensible baseline
  • 4. Model ranges, not theater
  • 5. Match proof to the claim
  • 6. Artifact: customer business case

1. Define value from the customer side

Value compares relevant benefits and total sacrifices with an alternative. Benefits include revenue, cost, risk, time, quality, strategic option value, and experience. Sacrifices include price, implementation, disruption, learning, switching, governance, and opportunity cost.

2. Build a value driver tree

Link capability → workflow change → operational metric → financial or strategic result. Keep units explicit. For example: hours saved × loaded labor cost × realistic adoption, minus implementation and operating cost. Avoid counting the same benefit twice.

3. Establish a defensible baseline

Use customer data, then triangulate with samples, logs, audited reports, or bounded estimates. Record source, owner, period, and confidence for every input. If the baseline is disputed, the ROI is decoration.

4. Model ranges, not theater

Create downside, base, and upside cases. Show time to value, cash-flow timing, payback, net present value when relevant, and sensitivity to the assumptions with greatest leverage. Separate one-time from recurring impact and realized from addressable value.

5. Match proof to the claim

Testimonials support perceived experience, not universal results. Use comparable evidence, pilots, references, technical tests, and commitments according to risk. Label modeled, observed, and guaranteed outcomes differently. Include status quo, alternatives, risks, owners, and stop criteria.

6. Artifact: customer business case

Deliver a value driver tree, source ledger, three-scenario model, sensitivity analysis, proof map, implementation costs, risks, and one-page executive memo.
